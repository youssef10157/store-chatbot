Store

مساعد متجر ذكي يعمل بدون إنترنت
مشروع Store هو chatbot بسيط يساعد العملاء على استعراض المنتجات، ومعرفة الأسعار والكميات المتاحة، وتجهيز سلة مشتريات، وكل ذلك بدون الحاجة إلى اتصال بالإنترنت.

أهداف المشروع

  • توفير واجهة محادثة بسيطة وسهلة لعملاء المتجر.
  • عرض كتالوج محلي يحتوي على المنتجات والأسعار والمخزون.
  • السماح للعميل بالبحث عن منتج وإضافته إلى سلة المشتريات.
  • الحفاظ على سرعة التطبيق وخصوصية البيانات وتقليل استهلاك الإنترنت.

المميزات الرئيسية

  • عرض قائمة المنتجات المتاحة، مثل القمصان والبناطيل والأحذية والحقائب.
  • معرفة سعر المنتج والكمية المتاحة منه.
  • إضافة المنتجات إلى السلة وحساب الإجمالي تلقائيًا.
  • عرض مواعيد العمل ومعلومات التوصيل.
  • واجهة رسومية تدعم اللغة العربية.
  • يعمل أوفلاين تقريبًا بدون استهلاك للإنترنت.

رابط النسخة الأونلاين

يمكن فتح مساعد Store من أي جهاز عبر الرابط:
https://youssef10157.github.io/store-chatbot/

التقنيات المستخدمة

  • لغة البرمجة Python 3.
  • مكتبة Tkinter لإنشاء واجهة سطح المكتب.
  • بيانات المنتجات محفوظة محليًا داخل البرنامج.
  • لا يستخدم API خارجيًا أو خدمات سحابية.

أمثلة على الأوامر

  • المنتجات: عرض الكتالوج والأسعار والمخزون.
  • سعر حذاء رياضي: معرفة سعر وتوافر المنتج.
  • اضف حذاء رياضي: إضافة منتج إلى السلة.
  • السلة: عرض محتويات السلة والإجمالي.
  • مساعدة: عرض الأوامر المتاحة.

طريقة التشغيل

  1. تثبيت Python 3 على الجهاز.
  2. فتح مجلد المشروع.
  3. تشغيل الملف chatbot_gui.py.
  4. كتابة الطلب داخل نافذة Store والضغط على زر إرسال.

التطويرات المستقبلية

  • حفظ المنتجات والطلبات داخل قاعدة بيانات.
  • إضافة لوحة تحكم لتعديل الأسعار والمخزون.
  • إنشاء فواتير قابلة للطباعة.
  • إضافة سجل لطلبات العملاء ومتابعة التوصيل.
